# Editorial marks for what-is-2r.md

# Applied by scripts/editorial.py. See issue #1 for why this file exists
# and why the marks live here rather than inline in the Markdown.
#
#   standfirst:       promote a paragraph the author already wrote.
#                     Verified against the source — the build fails if it
#                     is not found.
#   standfirst-text:  a standfirst the editor wrote, inserted after the
#                     chapter heading. Authored, so it cannot be verified.
#   pullquote:        a sentence lifted verbatim from the chapter. Named,
#                     not copied — what gets typeset is the text as it
#                     appears in the Markdown, so it cannot drift.
#
# ---------------------------------------------------------------------
# HOW TO DO THE EDITORIAL PASS
#
# Everything below that starts with "#|" is a PROPOSAL, not a decision.
# To accept one, delete the "#|" and the space after it. To reject it,
# delete the line. Roughly five minutes a chapter.
#
# The two marks that are already active are not judgement calls: they are
# paragraphs the authors themselves wrote as bare claims, in bold, at the
# top of a chapter. Everything else needs a human.
#
# Selection constraints these proposals were generated against (also in
# skills/pdf-report/SKILL.md step 5):
#   - verbatim, never paraphrased
#   - 12-30 words, one or two sentences, self-contained (no "this", "it")
#   - a claim, not a fact or a list item
#   - never within two paragraphs of a figure, block quote or another
#     pull quote
#   - roughly one per 2-3 pages, never two on a spread
#   - never the chapter's first or last sentence, never the standfirst
#   - no inline Markdown emphasis inside the lifted span, which would
#     otherwise be escaped into literal asterisks
# ---------------------------------------------------------------------

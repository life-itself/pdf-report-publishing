# Exemplar reports

Third-party reports used as design references, all published freely on
the open web and all sourced from Rufus's Are.na board
[report-inspirations-for-life-itself](https://www.are.na/rufus-pollock/report-inspirations-for-life-itself).

Committed rather than fetched-on-demand so the design work has a stable
base that doesn't depend on those URLs still resolving. Re-fetch with
`scripts/fetch-exemplars.sh` if they need refreshing.

**These are other organisations' work, held here for study only.** Nothing
in them is ours to reuse — not the text, not the artwork, not the fonts
(CRI's Freight and the Mindfulness Initiative's ITC Avant Garde are both
commercially licensed). What we take from them is *approach*: grid,
hierarchy, page furniture, how figures and quotations are handled.

| `pci-planetary.pdf` | Planetary Civics Inquiry, *A New Framework for Planetary Futures* (Apr 2024) | Inter | Inter + DM Mono | 46, A4 |

Fonts read out with `pdffonts <file>` — a fast way to find out what a
design you admire is actually set in.

See `docs/typography-research.md` for what was extracted from them.
